## Install

<div class="install-command">

```bash
npx skills add swarupdonepudi/skills
```

</div>

The [skills CLI](https://github.com/vercel-labs/skills) detects the agents on your machine and asks whether to install for this project or globally. Claude Code users can also run `/plugin marketplace add swarupdonepudi/skills`.

## Where these come from

Each skill here is something that ran for a long time as a working practice before it became a skill. The `projects` skill grew out of the framework that carried some 350 pieces of multi-session work to completion across [Planton](https://planton.ai) and [Stigmer](https://stigmer.ai), rebuilt from first principles for the Agent Skills format. The documentation on this site is rendered from the skills' own files on every build; there is no second copy to drift.
